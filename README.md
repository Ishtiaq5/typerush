# TypeRush

A premium, distraction-free typing speed test that runs entirely in the browser.

## Features

- Live WPM, accuracy, error count and countdown while you type
- Character-accurate feedback: correct chars, wrong chars, missed chars and over-typed extras
- Word stream that scrolls with your line, with a glowing caret
- Animated results gauge (SVG), per-second pace chart and consistency score
- Personal best board persisted in localStorage (best WPM, best accuracy, tests taken)
- 15 / 30 / 60 / 120 second modes, keyboard shortcuts (Tab restarts, Esc resets)
- Responsive from 360px up, semantic HTML with ARIA labels

## Stack

Vanilla HTML5 + CSS3 + JavaScript. No frameworks, no CDN, no build step.

## Run it

Open index.html in a browser, or serve the folder with any static server.
